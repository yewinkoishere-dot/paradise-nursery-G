# Paradise Nursery Shopping Application

## Project Overview
Paradise Nursery is an online houseplant shopping application built with React. Customers can explore houseplants, browse plant categories, add plants to their cart, and manage their orders.

## Features
- Beautiful landing page with a background image
- About Us page describing the company
- Three houseplant categories with six plants each
- Product thumbnails, names, and prices
- Add to Cart functionality
- Dynamic shopping cart item counter
- Increase and decrease product quantities
- Remove products from the cart
- Automatic calculation of item totals and cart total
- Checkout message displaying "Coming Soon"
- Continue Shopping button
- Responsive navigation and layout

## Technologies
- React
- Vite
- Redux Toolkit
- React Redux
- React Router DOM
- CSS

## How to Run
1. Install the project dependencies using `npm install`.
2. Install the required libraries using `npm install @reduxjs/toolkit react-redux react-router-dom`.
3. Start the development server using `npm run dev`.
